# 🚀 Быстрая настройка Frontend через ngrok

## Если у вас уже запущен ngrok для FastAPI

### Автоматическая настройка (рекомендуется)

Просто запустите скрипт:
```bash
./setup_ngrok_frontend.sh
```

Скрипт автоматически:
1. ✅ Проверит, что ngrok запущен
2. ✅ Найдет ваш ngrok URL
3. ✅ Соберет frontend
4. ✅ Настроит все .env файлы
5. ✅ Пересоберет frontend с правильным API URL

### Ручная настройка

#### 1. Узнайте ваш ngrok URL

Откройте терминал где запущен ngrok, там будет что-то вроде:
```
Forwarding  https://abc123.ngrok-free.app -> http://localhost:8000
```

Скопируйте HTTPS URL (например: `https://abc123.ngrok-free.app`)

#### 2. Соберите frontend

```bash
cd app/static
npm install
npm run build
```

#### 3. Настройте .env файлы

**В корне проекта** (`.env`):
```env
FRONT_SITE=https://ваш-ngrok-url.ngrok-free.app/static
```

**В app/static/.env** (создайте если нет):
```env
VITE_API_URL=https://ваш-ngrok-url.ngrok-free.app
```

#### 4. Пересоберите frontend

```bash
cd app/static
npm run build
```

#### 5. Перезапустите FastAPI

Остановите сервер (Ctrl+C) и запустите снова:
```bash
python -m uvicorn app.main:app --reload
```

## Проверка

1. Откройте в браузере: `https://ваш-ngrok-url.ngrok-free.app/static`
2. Должна открыться ваша страница
3. В Telegram боте нажмите "🔖 Записаться"
4. Должно открыться Mini App

## Важно!

- ✅ URL должен быть **HTTPS** (ngrok дает HTTPS автоматически)
- ✅ URL должен заканчиваться на `/static`
- ✅ После изменения `.env` нужно **перезапустить FastAPI**
- ✅ После изменения `app/static/.env` нужно **пересобрать frontend**

## Структура

```
ngrok URL: https://abc123.ngrok-free.app
├── /webhook          → webhook для бота
├── /service          → API endpoints
├── /bookings/...     → API endpoints  
└── /static           → Frontend (React app)
    ├── index.html
    └── assets/...
```

## Проблемы?

**"404 на /static"**
→ Убедитесь что собрали frontend: `cd app/static && npm run build`

**"API не работает"**
→ Проверьте `VITE_API_URL` в `app/static/.env`

**"Кнопка открывает браузер вместо Mini App"**
→ Проверьте что `FRONT_SITE` начинается с `https://` и заканчивается на `/static`
