# Админ панель

## Доступ

Админ панель доступна только пользователям, которые находятся в `ADMIN_IDS` в файле `.env`:

```env
ADMIN_IDS=[123456789, 987654321]
```

Или пользователям с флагом `is_admin=true` в базе данных.

## Как получить доступ

1. Пользователь должен быть в `ADMIN_IDS` в `.env`
2. Или иметь `is_admin=true` в таблице `users`
3. В главном меню бота появится кнопка "⚙️ Админ панель"
4. При нажатии откроется Mini App с админ панелью

## Функционал

### Главная страница (`/admin`)
- Статистика: количество пользователей, услуг, мастеров, бронирований
- Статистика по статусам бронирований
- Навигация к разделам управления

### Управление пользователями (`/admin/users`)
- Просмотр всех пользователей
- Изменение статуса администратора
- Просмотр информации о пользователях

### Управление услугами (`/admin/services`)
- Просмотр всех услуг
- Создание новой услуги
- Редактирование услуги
- Удаление услуги
- Управление активностью услуги

### Управление мастерами (`/admin/masters`)
- Просмотр всех мастеров
- Создание нового мастера
- Редактирование мастера
- Удаление мастера
- Управление активностью мастера

### Управление бронированиями (`/admin/bookings`)
- Просмотр всех бронирований
- Изменение статуса бронирования (new, confirmed, cancelled, completed)
- Удаление бронирования
- Просмотр детальной информации

## API Endpoints

Все админ endpoints требуют параметр `telegram_id` для проверки прав:

- `GET /admin/stats?telegram_id={id}` - статистика
- `GET /admin/users?telegram_id={id}` - список пользователей
- `PUT /admin/users/{user_id}/toggle-admin?telegram_id={id}` - переключить админа
- `GET /admin/services?telegram_id={id}` - список услуг
- `POST /admin/services?telegram_id={id}` - создать услугу
- `PUT /admin/services/{id}?telegram_id={id}` - обновить услугу
- `DELETE /admin/services/{id}?telegram_id={id}` - удалить услугу
- `GET /admin/masters?telegram_id={id}` - список мастеров
- `POST /admin/masters?telegram_id={id}` - создать мастера
- `PUT /admin/masters/{id}?telegram_id={id}` - обновить мастера
- `DELETE /admin/masters/{id}?telegram_id={id}` - удалить мастера
- `GET /admin/bookings?telegram_id={id}` - список бронирований
- `PUT /admin/bookings/{id}/status?status={status}&telegram_id={id}` - изменить статус
- `DELETE /admin/bookings/{id}?telegram_id={id}` - удалить бронирование

## Безопасность

- Все админ endpoints проверяют права доступа через `verify_admin` dependency
- Проверка происходит на уровне API
- Frontend также проверяет доступ при загрузке страниц
- При отсутствии прав возвращается 403 Forbidden
