# Nails Bot Frontend

Telegram Mini App для системы бронирования услуг мастеров маникюра/педикюра.

## Технологии

- React 18
- TypeScript
- @tma.js/sdk-react - Telegram Mini Apps SDK
- @telegram-apps/telegram-ui - UI компоненты Telegram
- React Router DOM - маршрутизация
- Vite - сборщик

## Возможности

### Главная страница
- Отображение всех текущих бронирований пользователя
- Автоматическое скрытие прошедших записей
- MainButton для создания новой записи
- Переход к детальной информации о записи

### Создание бронирования
- Выбор услуги из списка активных услуг
- Выбор мастера, который предоставляет выбранную услугу
- Выбор даты (на 3 месяца вперед)
- Выбор времени с отображением занятых слотов (приглушенные кнопки)
- Ввод контактных данных (имя, телефон)
- Подтверждение записи через MainButton

### Детальная информация о бронировании
- Просмотр всех деталей записи
- Возможность отменить запись (если статус позволяет)

## Установка и запуск

### 1. Установка зависимостей

```bash
npm install
# или
pnpm install
```

### 2. Настройка переменных окружения

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Отредактируйте `.env`:

```
VITE_API_URL=https://your-ngrok-url.ngrok.io
```

**Важно**: Для работы с Telegram Mini App необходимо использовать HTTPS. Используйте ngrok или другой туннель для локальной разработки.

### 3. Запуск в режиме разработки

```bash
npm run dev
# или
pnpm dev
```

Приложение будет доступно по адресу `http://localhost:5173`

### 4. Запуск с HTTPS (для тестирования в Telegram)

```bash
npm run dev:https
# или
pnpm dev:https
```

Приложение будет доступно по адресу `https://localhost:5173`

### 5. Сборка для продакшена

```bash
npm run build
# или
pnpm build
```

Собранное приложение будет находиться в папке `dist/`.

## Настройка ngrok для локальной разработки

### Шаг 1: Запустите backend

```bash
cd /path/to/nails-bot
source venv/bin/activate
uvicorn app.main:app --reload --port 8000
```

### Шаг 2: Запустите ngrok для backend

```bash
ngrok http 8000
```

Скопируйте HTTPS URL (например, `https://abc123.ngrok.io`)

### Шаг 3: Обновите .env фронтенда

```
VITE_API_URL=https://abc123.ngrok.io
```

### Шаг 4: Запустите frontend

```bash
npm run dev:https
```

### Шаг 5: Запустите ngrok для frontend (в новом терминале)

```bash
ngrok http 5173
```

Скопируйте HTTPS URL фронтенда

### Шаг 6: Настройте WebApp в Telegram Bot

Отправьте команду `/setmenubutton` боту @BotFather и укажите URL фронтенда из ngrok.

Или обновите кнопку в коде бота (`app/tg_bot/kbs.py`):

```python
def _get_main_button():
    return KeyboardButton(
        text='📱 Открыть приложение',
        web_app=WebAppInfo(url='https://your-frontend-ngrok-url.ngrok.io')
    )
```

## API Endpoints

### Пользователи
- `POST /users` - Создать или получить пользователя

### Услуги
- `GET /services` - Получить все услуги
- `GET /services/{id}` - Получить конкретную услугу

### Мастера
- `GET /masters` - Получить всех мастеров
- `GET /masters/{id}` - Получить конкретного мастера
- `GET /masters/by-service/{service_id}` - Получить мастеров по услуге

### Бронирования
- `GET /bookings/{telegram_id}` - Получить бронирования пользователя
- `GET /booking/{id}` - Получить конкретное бронирование
- `POST /booking` - Создать бронирование
- `PUT /booking/{id}` - Обновить бронирование
- `DELETE /booking/{id}` - Удалить бронирование
- `GET /bookings/master/{master_id}?date=YYYY-MM-DD` - Получить занятые слоты мастера

## Особенности

- Генерация слотов с интервалом 30 минут

## Troubleshooting

### Проблема: "Telegram user data not available"
**Решение**: Убедитесь, что приложение открыто внутри Telegram, а не в обычном браузере.

### Проблема: "Failed to fetch"
**Решение**: Проверьте, что:
1. Backend запущен
2. `VITE_API_URL` в `.env` указывает на правильный URL
3. CORS настроен на backend

### Проблема: Белый экран в Telegram
**Решение**: 
1. Проверьте console в Eruda (встроенный devtools для TMA)
2. Убедитесь, что используется HTTPS URL
3. Проверьте, что приложение собрано правильно (`npm run build`)
